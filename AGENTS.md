Strict RFC 8259 JSON parser and serializer for AutoHotkey v2, maintained by AI Ascend Lab. The published surface is `AHK20_JSON.ahk`.

Do not resurrect `thqby-JSON/` or the full nst/JSONTestSuite clone.

## Language

Comments, throw messages, and user-facing strings in `AHK20_JSON.ahk`, `test/*.ahk`, and `examples/*.ahk` are English.

## Commands

Requires AutoHotkey v2. Typical path: `C:\Program Files\AutoHotkey\v2\AutoHotkey64.exe`.

```powershell
# Same as CI
powershell -NoProfile -ExecutionPolicy Bypass -File .\test\check.ps1

# Optional JSONTestSuite (318 files)
powershell -NoProfile -ExecutionPolicy Bypass -File .\test\check.ps1 -Suite
```

`make check` / `make test-suite` call the same script. CI does not install AutoHotkey; it unpacks the pinned portable zip and points `AHK20_JSON_AHK` at it. Use the same variable locally for a non-default path.

Expect JSONTestSuite: **318** cases, **283 PASS / 0 FAIL / 35 INFO**.

Copy `TestSamples` as raw bytes. Do not round-trip them through a text editor or UTF-8 `FileRead`.

## API (do not change without tests)

```ahk
JSON.Version
JSON.Parse(text, keepBoolType := true, asMap := true, allowComments := false, rejectDuplicateKeys := true, maxDepth := 256)
JSON.Stringify(value, expandLevel := unset, space := "  ", maxDepth := 256)
JSON.true / JSON.false / JSON.null
JSON.Bool(value)
JSON.IsTrue(value) / JSON.IsFalse(value) / JSON.IsNull(value)
```

Version is local SemVer. `JSON.Version`, the file-header `@version`, and the latest `## [x.y.z]` heading in `CHANGELOG.md` must be the same string. Unit tests enforce that.

- Default `asMap := true`. Prefer Map over plain Object.
- Default `keepBoolType := true`. AHK `true`/`false` are integers `1`/`0`.
- `allowComments := true` parses JSONC, not strict JSON.

## Parser / serializer rules

Stay strict. Do not accept broken JSON.

- Top-level scalars are valid.
- JSON numbers: no leading zeros, no `1.`, no `.5`; exponent sign is optional.
- Only whitespace is space / Tab / CR / LF.
- Raw U+0000 is not whitespace. Trailing `123` + NUL must be rejected.
- Do not use `InStr(" `t`r`n", ch)` to detect whitespace.
- `StrGet` truncates at U+0000; `JSONTestAdapter.ahk` rebuilds the string.
- Unescaped U+0000–U+001F in strings are illegal. Stringify remaining controls as `\uXXXX`, never `\v`.

## Style

- AutoHotkey v2 only (`#Requires AutoHotkey v2.0`).
- Nested functions inside `Parse` / `Stringify` are closures. Do not reuse the name `result`.
- Comments explain non-obvious constraints.
- Keep changes scoped.

## Boundaries

- Do not commit `vibecoding/`, secrets, `.env`, keys, or `*.pem`.
- Do not force-push or rewrite published history.
- Do not add a `scripts/` directory. Tooling lives in `test/` and is wrapped by `Makefile`.
- Do not add a CI badge until the workflow has passed on GitHub.

## After library changes

1. If public behavior changed, bump `JSON.Version`, `@version`, and `CHANGELOG.md` together.
2. Run `test/check.ps1`.
3. If the parser changed, run `test/check.ps1 -Suite` and keep 0 FAIL.
4. If you touch UTF-8 / NUL handling, re-check `n_multidigit_number_then_00.json`.
